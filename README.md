**[LayoutLab](https://github.com/junpat32/layoutlab-ci)** explores how Parquet storage choices affect analytical SQL workloads. It combines computational intelligence experiments, reproducible evaluation, and a desktop explorer for saved results.

- **Experiment:** compare partitioning, sort order, compression, row-group size, and file size.
- **Validate:** check query correctness and compare layouts through paired benchmarks.
- **Explore:** inspect measured results and clearly labelled estimates in a Python desktop app.
